# 百度网盘字体安装（v1.6）

在左侧选择「网盘字体安装」，粘贴分享链接或整段分享文字，再点击打开。链接中的 `pwd` 或分享文字里的四位提取码会自动识别。必要时在软件内的百度页面完成登录、提取码或验证码操作；百度登录状态由系统 WebKit 保存。

## 网页下载与自动安装

软件识别当前网页中可见的 TTF、OTF、TTC 和 ZIP 文件名称，并尝试使用页面普通的选择及下载按钮。它不使用未经授权的下载接口，不读取密码输入框或导出登录 Cookie。

百度可能要求手动点击、客户端、会员权限或验证，页面结构也可能变化。因此网页自动下载是尽力尝试，不能保证任何分享都能无人值守下载。文件夹需在页面中打开，ZIP 内的字体需下载后才能识别。

只要网页向软件提供实际下载，后续处理会自动进行：

1. 下载到软件独立的临时任务目录。
2. 读取字体内部的 PostScript 名称，与 macOS 已启用的字体比较；已有字体跳过。网页文件名不足以可靠判定字体身份，因此精确查重发生在下载后。
3. 缺失字体复制到当前用户的 `~/Library/Fonts`，注册并核实 macOS 可用字体列表。
4. 一次任务中所有字体均安装成功或已存在时，删除该任务的临时下载与解压文件。安装的字体保留。

TTC 中部分字体已安装时保留文件供手动处理，避免覆盖现有字体。损坏、受密码保护或没有字体的 ZIP 不会报告成功。失败任务保存在 `~/Library/Application Support/FontFinder/DownloadJobs`，可以从界面打开目录。

## 百度要求使用客户端时

先使用百度网盘下载，再点击「导入下载文件」，选择字体、ZIP 或文件夹。软件会自动查重、安装和清理自己的临时副本。默认保留用户选择的原文件；如希望安装后删除原下载文件，可勾选对应选项，成功后单独选择的文件会移到废纸篓。文件夹导入始终保留原文件夹及其内容。

## 处理范围

- 单次下载或导入文件上限 512 MiB，单个字体/解压项目上限 256 MiB。
- ZIP 最多嵌套三层，累计解压上限 1 GiB、10,000 个项目；拒绝路径穿越和符号链接。
- 每次文件夹导入最多扫描 1,000 个支持的文件。
- 安装到当前 Mac 用户，其他设备需重新下载；本版本没有邮箱账号或用户云端记录。
- 软件不需要 GitHub 令牌、Supabase 配置或百度开发者应用。之前的 GitHub 字体文件与旧版下载保留在仓库中。

macOS 自动化测试包含真实字体持久安装、重复跳过、嵌套 ZIP、临时文件清理、失败保留及本地 WebKit 文件名识别；这些不等于百度实际登录、验证码或分享下载已经实测。
