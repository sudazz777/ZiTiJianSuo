# 字体检索 Font Finder · 1.14

好字体，随手就能找到。

字体检索是一款离线运行的 Mac 字体名称工具。输入中文、拼音、拼音首字母或英文，即可查找本机字体，预览效果，并一键复制名称。

## 安装与启动

1. 退出旧版，打开 `FontFinder-macOS-Universal-v1.14.dmg`。
2. 安装窗口中，左侧是「字体检索.app」，右侧是「应用程序」快捷方式；将左侧应用拖到右侧，已有旧版时选择替换。
3. 在「应用程序」中打开「字体检索」，然后推出安装磁盘。

支持 Apple 芯片与 Intel Mac，部署目标为 macOS 13 或更新版本。当前安装验证使用 macOS 14 的 Apple 芯片 CI 环境；Intel 完成交叉编译。原始 v1.4 的测试记录见随附历史验证文件。

应用使用本地 ad-hoc 签名，尚未完成 Developer ID 签名或 Apple 公证。如果其他 Mac 首次打开时提示无法验证开发者，请先尝试打开一次，再前往「系统设置 → 隐私与安全性」找到该应用的提示，选择「仍要打开」。仅在你确认使用的是这份应用时进行确认；不需要关闭系统的安全保护。

Apple 官方说明：https://support.apple.com/zh-cn/102445

正式对外发布、希望减少首次打开提示时，需要使用你自己的 Developer ID Application 证书签名并提交 Apple 公证。这一步尚未执行。

## 搜索字体

在顶部输入框中搜索，例如：

| 输入 | 搜索方式 |
| --- | --- |
| 苹方 | 中文名称或常见搜索别名 |
| pingfang / ping fang | 拼音，支持不带声调与带声调输入 |
| pf | 拼音首字母 |
| PingFang | 英文名称，不区分大小写 |
| PingFangSC-Regular | PostScript 名称 |

搜索会覆盖字体内置名称、英文名、中文名、自动生成的拼音和自定义别名。搜索别名只帮助查找，不会被冒充为字体官方名称。

左侧可切换「全部字体」「中文字体」「我的收藏」「最近复制」，点击分类行的图标、文字、数量或空白处均可切换。中文字体分组根据字体自身是否包含“中文”两个测试字符的字形筛选，不能代表覆盖所有汉字。收藏与最近复制记录会在本机保留。

## 本地字体管理（v1.14）

点击左侧「最近复制」下方的「本地字体管理」，以多列卡片查看字体效果；窗口变宽时会自动增加每行卡片数量。这里与「全部字体」共用字体册已启用的字体家族列表，同一家族的字重合并成一张卡片。每张卡片显示中英文名称、样式数量和真实字体预览。西文字体在预览文字含汉字时使用英文示例，避免缺字时仅看到系统备用字体。顶部可修改预览文字和字号。点击右上角当前排序名称，可直接选择英文名 A–Z/Z–A、中文拼音 A–Z/Z–A、最近复制优先或默认排序；与全部字体共用并记住排序选择，切换排序不会清空多选。

支持中文、拼音、英文名称、别名、文件名或路径搜索。点击卡片可选择或取消选择该家族，勾选后卡片会高亮。「只看可删除字体」用于筛选可操作项；「全选可删除项」只勾选当前筛选结果中允许删除的家族。切换筛选不会取消已选字体，工具栏显示所选家族数量及实际文件数量。

点击「删除已选」后会弹出二次确认窗口，列出所选文件的字体名称、样式数量和完整路径。选择「取消」不会修改字体；确认「移到废纸篓」后才开始批量处理，并逐项显示成功或失败结果。失败的文件会保留。

管理列表读取已安装并启用的字体，按家族显示。选中家族会包含该家族的全部字体文件，多个家族共用的文件在删除清单中只出现一次。TTC 等字体集合中的多个家族或字重共用一个文件，删除该文件时会一起移除。系统字体受保护，不能勾选；仅允许操作当前用户 `~/Library/Fonts` 和共享 `/Library/Fonts` 中有权限管理的普通字体文件，其他位置可通过「查看位置」在访达中管理。移除共享字体可能影响其他用户，正在使用该字体的软件可能需要重新打开。

文件使用 macOS 的废纸篓接口移动，不会直接永久删除。误删时可点击「打开废纸篓」，在访达中将字体还原，必要时在「字体册」重新启用，再刷新本软件。已移到废纸篓的字体不会出现在字体列表中。

## 字体来源与字重合并

通过 macOS CoreText 读取本机已启用、持久注册并且有实际字体文件的字体，排除隐藏字体、未下载字体以及应用临时加载或应用包内的字体。这里读取的是系统字体注册信息，不是读取字体册应用窗口。

同一字体家族的 Regular、Light、Bold、Italic 等样式合并成一行，在右侧“字重 / 样式”中切换预览。简体、繁体和不同宽度家族仍分开显示。

旧版按单个字重记录的收藏、最近复制和别名会迁移到家族条目；同一家族重复的收藏和最近记录会合并。多个字重存在不同别名时，采用常规样式优先的一个别名。字体安装或启用状态发生变化后，会重新读取字体；也可按 ⌘R 手动刷新。

## 字体排序

点击字体列表右上角当前排序名称（例如「英文名 A–Z」），直接显示以下选项。当前选项带勾选，无需再进入子菜单：

| 排序方式 | 效果 |
| --- | --- |
| 英文名 A–Z | 按英文名称升序排列，新安装版本默认使用此项 |
| 英文名 Z–A | 按英文名称降序排列 |
| 中文拼音 A–Z | 按中文名的拼音升序排列；没有中文名时使用英文名 |
| 中文拼音 Z–A | 按中文名的拼音降序排列；没有中文名时使用英文名 |
| 最近复制优先 | 最近复制的字体排在前面，其余按英文名 A–Z 排列 |
| 默认排序 | 恢复应用原来的排列方式；最近复制分组按复制先后顺序排列 |

排序会应用于全部字体、中文字体、收藏、最近复制和搜索结果。选择会自动保存在本机，下次打开仍会使用。自定义别名也参与排序，编辑后会立即更新位置；只改变顺序时会保留当前选中的字体。

英文排序忽略大小写，数字使用自然顺序，例如 `Font 2` 排在 `Font 10` 前面。

## 一键复制

字体列表下方直接提供「复制中文」「复制英文」。点击一行，可在右侧查看中文、英文名称和预览。

| 快捷键 | 功能 |
| --- | --- |
| ⌘F | 聚焦字体搜索 |
| ⌘R | 重新读取本机已安装字体 |
| ⌘D | 收藏或取消收藏当前选中的字体 |
| ⌘1 | 复制中文名称 |
| ⌘2 | 复制英文名称 |
| 搜索框内回车 | 复制当前选中字体的英文名称 |

复制后界面底部会出现提示，可在其他软件中使用 ⌘V 粘贴。点击输入框外的卡片、按钮、侧栏或空白处，可取消输入光标；再次点击搜索框或按 ⌘F 可继续输入，点击其他输入框也可直接编辑。

中文名称来自字体的中文元数据。没有中文名称时，中文复制按钮会禁用；你可以在详情中添加自定义中文别名。拼音用于搜索索引，不提供单独的拼音复制入口。

中文和英文复制区使用字体家族名称，不带 Regular、Light、Bold 等字重后缀；具体字重在预览区单独切换。英文名称优先读取字体内置的英文家族名称。

中文、英文名称或自定义别名作为文本复制后，并不保证能被每个设计软件的字体选择器识别。

## 预览与别名

在右侧预览区输入任意文字，并拖动滑块调整字号。字体缺少某个字符时，macOS 可能用备用字体显示该字符。

点击「编辑中文 / 英文别名」可自定义搜索与复制名称。拼音自动更新，别名只保存在本机，不修改字体文件。留空或使用「恢复原名」后点击保存，即可恢复原始名称。

## 在其他电脑使用

把同一个 DMG 安装包复制给其他 Mac 即可安装。应用不依赖本机源码路径，不需要联网。

每台电脑读取的是各自安装的字体，不会把原电脑的字体文件一起带走。要得到相同字形，需要在目标电脑另外安装相同字体，并遵守该字体的授权。收藏、别名和最近复制记录目前不会自动同步。

## 源码与构建

源码位于 `Source/`，使用 Swift、SwiftUI、AppKit、CoreText 与 Foundation。安装 Apple Command Line Tools 或 Xcode 后，在此目录运行：

```bash
./build.sh
```

脚本编译 arm64 和 x86_64 两个分支，再合并为 Universal 应用，并执行本地签名。字体枚举、名称解析、拼音转换和剪贴板全部使用系统 API；没有第三方运行时依赖。

运行内置测试：

```bash
"字体检索.app/Contents/MacOS/FontName" --self-test
```

测试需要正常访问 macOS 字体服务和剪贴板。内置测试会使用独立临时偏好设置域和独立剪贴板，不会替换你当前复制的内容。

保存应用自身的界面截图：

```bash
"字体检索.app/Contents/MacOS/FontName" --capture /tmp/fontname-preview.png
```

测试已覆盖字体元数据解析、损坏数据、中文/拼音/英文/首字母搜索、真实安装字体、字形检查、收藏、别名、最近复制、中文与英文两种剪贴板内容、六种排序、搜索和收藏排序、自定义别名重排、排序选择持久化和偏好设置持久化。

## 查看字体文件位置（v1.8）

点击字体卡片右下角的「查看字体位置」，在访达中选中对应文件。鼠标悬停在按钮上可查看完整路径。若在右侧切换了字重或样式，按钮会定位该样式实际使用的文件。若文件已移动或不可访问，先按 ⌘R 刷新字体列表后重试。

## 检查更新与自动安装（v1.14）

在 macOS 菜单栏选择「字体检索 → 检查更新…」，可手动查看新版本。软件每次启动时自动检查一次，不进行定时后台检测。启动检查返回时若软件在后台，提示会等回到软件后显示。

发现新版本时，弹窗显示版本号、更新说明及以下选项：

- 「更新并重启」：软件后台下载安装包，显示进度并校验文件大小、SHA-256、应用身份、版本、架构和代码签名完整性。准备完成后自动退出，使用独立安装助手替换应用，再重新打开新版。无需自己打开或拖拽安装包。
- 「稍后提醒」：等下次启动检查或手动检查时再提示。
- 「跳过此版本」：不再自动提示该版本；手动检查仍可查看，后续新版本仍会提醒。

下载期间可点击「取消更新」。字体批量操作完成前不会退出安装。下载失败或校验不通过不会替换原程序；安装或启动失败会尝试恢复旧版，保留恢复信息并提示手动安装。成功后会清理安装包与更新暂存文件，收藏、别名和最近复制仍保存在原来的本机偏好设置中。

自动更新支持 `/Applications/字体检索.app` 或 `~/Applications/字体检索.app`，要求当前账号对应用程序目录有替换权限。若正在 DMG、下载目录或其他位置运行，或没有写入权限，请先手动将应用安装到有权限的「应用程序」目录。软件不会自行提权或更改 macOS 的安全设置。应用仍采用 ad-hoc 签名，未完成 Apple Developer ID 签名和公证，macOS 仍可能要求确认打开。

**v1.13 及更早版本的更新按钮仍然只打开 DMG 下载链接，需要先手动安装 v1.14 一次。以后从 v1.14 更新到后续版本时，才能使用自动下载、安装与重启。** 首次安装仍可使用 DMG 拖拽，不提供 PKG 兼容包。

更新信息和安装包只来自本仓库的公开 GitHub Releases，不需要账号、令牌或额外服务器；发布仓库需保持 Public。检查更新不上传字体、收藏或别名，本机检索与复制不依赖网络。
