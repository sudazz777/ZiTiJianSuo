# v1.14 自动安装更新与界面调整

日期：2026-11-04；版本 1.14、构建 15。

- 更新来源保持 GitHub Releases。软件内选择「更新并重启」后，使用私有目录下载，限制包大小并流式核对大小和 SHA-256；仅接受 GitHub 的 HTTPS 下载与资源重定向。
- 只读挂载 DMG，检查应用标识、版本、处理器架构和签名完整性；在应用所在卷暂存。独立助手保留完整签名应用包，不依赖原应用在替换后仍存在。
- 助手就绪后，主程序再次确认取消状态及字体操作状态，并明确提交安装。助手等待旧进程退出，再核对原路径身份，使用原子交换替换程序；未提交或已取消的作业不得安装。启动失败会尝试回滚，无法确认启动结果时保留恢复副本，避免覆盖可能已运行的程序。
- 自动安装不提权，不移除隔离属性，也不改变系统安全设置。仅支持有权限写入的 `/Applications/字体检索.app` 或 `~/Applications/字体检索.app`，其他情况提供手动安装入口。
- 更新检查仍仅在每次启动或手动操作时执行。v1.13 及以前需手动安装本版一次，之后的新版本才支持自动安装。
- 本地字体管理与全部字体共用六种排序及持久化偏好；切换排序和筛选保留多选与精确文件清单。批量字体操作期间阻止更新退出。
- 点击当前窗口的非编辑区域取消文字焦点，不吞鼠标事件，点击其他输入框仍可直接编辑。移除宣传卡片顶部图案，保留文案。

测试仅操作 UUID 临时应用副本和测试字体，不替换用户软件或删除用户字体。运行环境为 macOS 14 Apple 芯片，包含 Intel 交叉编译；未验证所有 macOS 版本或 Intel 实机。应用仍使用 ad-hoc 签名，未完成 Developer ID 签名及公证。
