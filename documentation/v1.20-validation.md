# v1.20 代码清理与运行性能

日期：2026-11-05；版本 1.20、构建 21。

## 清理与优化

- 删除六个已停用的云端模块：云目录、云状态、云界面、云端检查、GitHub 字体客户端和钥匙串凭证管理。共删除 821 行旧模块；删除失效通知、类型别名、CLI 入口及旧使用说明。更新检查保留自己的独立网络模拟器。
- 加入缓存、回归检查和性能基准后，Swift 源码仍由 3903 行减至 3304 行，净减少 599 行。旧版本机名称兼容、字体文件、收藏、自动更新、删除保护及安装检查保留。
- 字体构造时去重搜索词、复用一次拼音转换生成首字母，并预计算默认字重及两类排序键。默认字重不再在每次预览时重新排序。
- 字体、旧版名称或相关排序数据变化时清除有序目录缓存；输入查询只做一次标准化，再过滤有序结果。连续搜索复用排序结果，收藏与最近复制继续按原规则筛选。
- 管理页复用同一顺序和搜索方法，家族索引仅在目录变化时重建。只在管理页实际打开时读取管理文件信息，预览控件的提示文字不再触发文件存在检查；真正定位和删除时仍进行原有验证。
- 合并 250 毫秒内的字体注册变化通知，移除每次切回前台的全量扫描。仍由系统字库变化通知和手动刷新更新数据，没有新增周期任务。未变化的偏好不重复写入，模型销毁时移除通知监听。

## 验证与测量

- [预发布构建](https://github.com/sudazz777/ZiTiJianSuo/actions/runs/41962307628) 成功，来源 `e2e370f`。本机功能 86 项、更新 46 项、运行缓存 9 项、字体管理 29 项、安装 31 项、焦点与窗口 15 项通过。已取消模块的检查随模块删除。
- 运行缓存检查验证新旧算法在 192 组分类、排序与查询组合中结果一致；覆盖目录替换、旧版名称更改/移除、最近复制排序更新和缺失字体过滤。
- 同一 CI 进程、同一份 480 字体数据、96 次按拼音排序的搜索：旧算法参考实现 1491.44 毫秒，缓存实现 161.70 毫秒，约 9.22 倍。参考实现在测试文件中保留原有步骤。该结果衡量数据处理热路径，不含完整 UI 绘制和字体文件首次加载，不代表整款软件的速度倍率；没有以耗时阈值作为测试成败条件。
- 已查看真实管理页截图，验证延迟建立管理目录后仍正常显示字体。DMG 挂载、Finder 布局、Applications 复制、签名和 Universal 架构检查通过。
- 实际运行环境为 macOS 14 Apple 芯片，未验证所有系统版本和 Intel 实机。仅在 GitHub Releases 发布，仍采用 ad-hoc 签名，未完成 Developer ID 签名或公证。
