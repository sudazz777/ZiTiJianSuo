# v1.21 侧栏响应与单次字体读取

日期：2026-11-05；版本 1.21、构建 22。

- 定位到本地管理页切入时同步构建文件目录、检查路径及权限的主线程阻塞。现在启动时后台构建管理快照，按字体目录版本缓存；普通切换和重入不再读取文件信息。重复请求合并，旧任务完成后也不能覆盖新版本结果。
- 普通字体卡片和管理卡片使用可比较的渲染数据，避免无关分类变化触发所有卡片重绘。选择、收藏、预览文字、字号、字重及路径等实际变化仍更新显示；已查看原生列表、网格和管理页截图。
- 按最新要求移除字体变化监听、延迟检测及扫描排队。启动读取一次，之后只由刷新按钮或 ⌘R 明确触发重新读取；切回前台、切换分类和重复点击当前分类都不触发检测。
- 删除成功后从现有缓存中移除对应文件与样式，更新检索和选择，不重新扫描系统字库。文件移动前仍保留权限、身份与有效字体校验，二次确认和废纸篓接口保留。失败时提示手动刷新，不自动检测。
- [预发布构建](https://github.com/sudazz777/ZiTiJianSuo/actions/runs/41965205938) 成功，来源 `83394b3`。本机功能 86 项、运行缓存 9 项、侧栏 18 项、字体管理 29 项、更新 46 项、安装 31 项、焦点和窗口 15 项通过；DMG 挂载、Applications 复制、签名和 Universal 架构检查通过。
- 新侧栏检查使用受控慢读取验证后台执行、主线程可继续切换、进行中请求去重、缓存重入、过期结果拒绝和手动刷新。另检查启动仅一次读取、连续切换不扫描、卡片实际数据变化仍刷新，以及移除部分/全部样式时缓存正确更新。
- 使用实际 178 个字体、循环五个分类三次，强制布局并生成 15 个 AppKit/SwiftUI 位图帧。平均 143.11 毫秒，最大 382.78 毫秒，包含调度等待及完整位图栅格化；没有旧版本 UI 基线，不将此数字用作交互延迟或流畅度保证。该检查同时验证重复渲染不重启文件检查。
- 实际环境为 macOS 14 Apple 芯片，未验证所有系统版本、用户全部字体集合或 Intel 实机。仅在 GitHub Releases 发布，仍采用 ad-hoc 签名，未完成 Developer ID 签名和公证。
